# Music Builder & Downloader

Небольшое GUI-приложение на Python, которое объединяет два шага в одном окне:

- собирает таблицу треков из текста;
- добавляет треки в очередь;
- скачивает их в `mp3` через `yt-dlp` и `FFmpeg`.

## Запуск

```bash
pip install -r requirements.txt
python music_app.py
```

## Что умеет

- открыть `.txt` со списком музыки или вставить текст вручную;
- показать готовую таблицу треков;
- сохранить таблицу в `CSV`;
- добавить выбранные треки или все сразу в очередь;
- скачать очередь в указанную папку без зависания интерфейса.

## Важно

- Для конвертации в `mp3` нужен установленный `FFmpeg` в `PATH`.
- Если часть треков не скачалась, ошибки сохраняются в `failed_downloads.txt`.

## Файлы

- `music_app.py` — основное приложение
- `tracks.csv` — пример готовой таблицы
- `downloads_mp3/` — папка для скачанных файлов
